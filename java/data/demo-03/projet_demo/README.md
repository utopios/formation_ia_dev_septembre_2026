# Projet de demonstration (bac a sable de l'agent)

Mini-service de calcul de remise commerciale et de facturation TTC, utilise
comme cible d'analyse par le mini-harness agentique (demos 3 et 4).

- `src/main/java/exemple/App.java` : logique metier (calculRemise, factureTtc).
- `src/test/java/exemple/AppTest.java` : tests unitaires.

Ce projet est volontairement minimal : il sert a montrer un agent qui explore
des fichiers, lit du code et repond a une question sur le projet.
